# Async Call Example

This repository contains an example of an asynchronous smart contract using the Massa blockchain framework. The contract demonstrates how to deploy a contract and schedule asynchronous calls. This contract is based on the Hello World example.

## Overview

The main functionalities of the contract include:

- **Constructor**: Initializes the contract and stores a message.
- **AsyncHello**: A function that triggers itself asynchronously every two periods.
- **SetMessage**: Updates the stored message in the contract.
- **GetMessage**: Retrieves the stored message from the contract.

## Getting Started

### Prerequisites

- Node.js
- npm
- Massa SDK

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/massalabs/massa-sc-examples.git
   cd massa-sc-examples/async-call
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

### Building the Contract

To compile the smart contract, run:

```bash
npm run build
```

### Deploying the Contract

To deploy the contract, run:

```bash
npm run deploy
```

### Triggering the Async Call

The async call is triggered by the `asyncHello` function. The first time it is called, it schedules the next call and so on.

To trigger the first async call, run:

```bash
npm run call
```

### Watching the Events generated by the Async Call

To watch the events, run:

```bash
npm run listen
```
